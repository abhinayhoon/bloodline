# C++ explained copies

Open this folder in VS Code to browse readable, commented reference copies of every C++ source and header file in the project. Each non-empty source line has a plain-language note immediately above it. The notes are explanations only; the original code lines are preserved below each note.

These files are **for reading**. Build and run the application from the project root, using the original files under `backend/` and `bloodline.cpp`.

To open this folder from the project root in VS Code, run `code cpp_explained`.

Start with `backend/src/main.cpp` for the server and `backend/include/bloodline/` for the model classes. `backend/tests/test_bloodline.cpp` contains unit tests. `backend/include/main.cpp` and `bloodline.cpp` are also included as found in the project.
